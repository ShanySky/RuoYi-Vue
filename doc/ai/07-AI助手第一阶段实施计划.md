## 5. 阶段 D：Frontend Tool Registry + 全局 AI Assistant

### 修改

- `src/ai/toolRegistry.js`
- `src/components/AiAssistant/index.vue`
- `src/api/ai/chat.js`
- `src/layout/index.vue` 挂载助手。

### Agent Turn 前端循环

```text
send user message
  → POST /ai/chat/turn
  → MESSAGE：展示并结束
  → TOOL_CALL：
       检查工具是否存在
       检查 risk
       WRITE/DANGEROUS_WRITE → 用户确认
       执行 handler
       POST toolResult
       继续循环
```

### 验收

- 所有登录后页面都能唤出助手。
- 模型下拉只显示 enabled 模型。
- 普通聊天成功。
- 当前页无工具时模型不会收到页面工具。
