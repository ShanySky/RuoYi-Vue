# 成熟执行框架与隔离工作空间方案

> 2026-09-21 / R1，自审通过，尚未实施。依据 29、D-002/003/007/008/017/018/023；候选证据 33；计划 38；动态记录 39。

## 1. 业务结果与验收标准

用户能够在本人授权内查询业务、完成分析，并生成可下载的表格、文档和 PDF；必要的业务写入仍逐次确认。较长任务能够停止，失败不遗留无界进程、文件或未知写入重试。客户端沿用既有聊天、确认和运行协议，只增加工作空间治理与成果入口。

| 标识 | 完成标准 | 有判别力的观察 |
|---|---|---|
| H-01 | 成熟框架实际负责模型与工具循环，身份和运行事实仍归若依 | 同一 Pi 会话连续模型请求、真实工具事件、等待确认期间没有下一次模型请求；页面工具与压缩仍成立 |
| H-02 | 每用户每任务隔离命令和文件，模型不获得宿主执行能力 | 实测越界路径、其他任务、网络、管理接口及凭据不可访问；默认工具不存在于实际输入 |
| H-03 | 字节、文件数、处理器、内存、进程、并发、时间在执行中受限 | 实际写满、建满文件、内存/进程超额、长命令；核对内核配置、运行结果与回收 |
| H-04 | 停止、失败、进程退出和后端异常后可终止并回收 | 主动停止与杀进程反例，数据库运行事实及容器/进程残留一致；未知业务写入不重试 |
| H-05 | 成果有容量、保留期、来源授权和下载保护 | 跨用户/任务、业务撤权、工作空间撤权、符号链接、到期、下载与清理并发、低磁盘拒绝 |
| H-06 | 三阶段组合任务和原功能可用，交付可复验 | 本人数据→隔离生成→授权下载；接口确认写入、页面工具、纠偏、压缩、刷新恢复、审计及迁移 |

## 2. 选型和最小集成

自主选择锁定 `@earendil-works/pi-coding-agent` 0.85.1（MIT，Node ≥22.19）；初步比较及原型见 33。采用 Java 后端管理的可信 Node 子进程，每运行独立会话。前端继续 Node 20，后端 Java 17，Node 单独指定绝对路径，不改机器默认环境。

Pi 实际负责调用模型、执行自定义工具回调、继续下一轮和取消。Java 不再每轮独立发起模型请求；现有协调器承接 Pi 的待执行事件、保存调用、执行授权及确认、回传真实结果。异步回调在若依完成授权和回执前暂停，下一模型轮前刷新获批工具及若依组装的历史/检查点，动态披露继续有效。压缩也使用同一 Pi 适配器的无工具短会话，不保留第二条长期聊天实现。模型目录检测保留原独立配置职责。

`AgentRuntimeRequest` 增加明确的运行关联；若依生成的调用标识、确认状态和业务结果为唯一持久事实。Pi 会话使用内存保存，不另写完整业务会话库。若依原历史、检查点、用量和审计继续生效。框架异常退出后旧运行失败并取消待办，保留已完成/未知调用事实；用户可发新指令，但系统不自动重放旧写入。多工具建议只按串行回调逐项重新鉴权和确认。

Node 只加载随包锁定的代码和自定义工具：关闭默认工具、扩展、技能、目录上下文、模板、主题、遥测和框架自动重试/自动压缩。凭据通过匿名管道按需交付，既不放命令行或环境，也不写进会话和工作空间。工具无法调用 Node 宿主命令。子进程使用最小环境、独立受控临时目录、有界协议输出、堆内存和运行时限，后端退出或输入管道关闭时主动结束。

## 3. 执行隔离和生命周期

可信工作空间服务部署在 Linux Docker 宿主，仅接受后端专用凭证和固定管理接口；它可管理容器，但容器内没有该凭证或 Docker 管理接口。随项目提供固定版本镜像构建和启动文件；本机使用专用 VirtualBox Linux 验证，生产不依赖 VirtualBox。

每 `(userId, runId)` 一个容器，创建参数由服务端固定：只读根文件系统、无网络、无宿主目录挂载、全部能力丢弃、禁止新增权限、独立进程/挂载命名空间。任务命令 UID 1000，保活进程使用另一无特权身份；根文件系统只提供 Python、shell 及固定文档生成库。临时工作目录使用内核有界的内存文件系统；不得把授权账号、模型令牌、数据库连接放入镜像或容器。

每命令结束后清理该任务身份的全部剩余进程；清理失败、命令超时、停止或内存故障直接终止并删除整个容器，不能只终止宿主的 Docker 命令客户端。后端每两秒续租活动工作空间，服务端租约失效最多 15 秒回收；单任务绝对寿命最多 30 分钟。服务重启清理所有自己标签下的旧任务容器，成果另行保留。管理失败关闭能力并给出固定可诊断错误，不退回宿主执行。

初始资源边界：每用户 2 / 全局 4 个活动任务；单容器 0.5 处理器、256 MiB 内存、内存与交换总量同值、32 进程、128 文件描述符；单命令最多 30 秒，输出最多 8 KiB。单文件最多 8 MiB；`/work` 64 MiB / 512 文件节点，`/tmp` 8 MiB / 64 节点，不提供额外可写共享内存。由完整预留计算用户和全局活动空间最多 144 / 288 MiB、1,152 / 2,304 节点，任务创建前原子检查，不依赖异步扫描拦截写满。

## 4. 工具、授权与成果

工作空间默认关闭，治理权限与使用权限分开：`ai:workspace:view/edit/use`。使用者须同时通过当前身份、运行归属、治理开关、工作空间服务健康和业务历史来源检查。治理关闭、身份改变或原业务授权撤销后，工具和成果均关闭；后台继续回收执行资源。

只增加任务执行、导入本人同运行结果、发布成果三个工具。执行和发布标记为受限工作空间操作 `WORKSPACE`，可自动执行，因为没有原业务写入和外部网络能力；原 `WRITE` 仍逐项人工确认。导入结果先按原句柄归属、到期、当前业务授权检查，再写任务输入文件，避免让模型反复携带大结果。文本输入和文件路径均有界，拒绝绝对路径、上跳及链接绕行。

发布时先终止本命令遗留进程，再通过只读固定导出程序读取正规单链接文件；逐级禁止符号链接，拒绝目录、设备、管道和链接文件，不在宿主直接解压模型文件。可信服务生成不可预测成果标识，原子预留后复制，保存大小和校验值；应用数据库保存归属、名称、会话来源与保留期限。传输或登记失败产生的残留由对账/到期清理回收，不因失败无限累加文件。

成果默认保留 24 小时，单任务 16 MiB / 8 文件，单用户 64 MiB / 32 文件，全局 256 MiB / 128 文件，单文件 8 MiB。临时任务结束即回收，不把未发布文件混作成果。成果目录仅可信服务可写，容量与文件数在复制之前原子核对；下载持有读取租约，清理不得删除正在读取的文件。过期不能新开下载，已开始读取受 60 秒上限约束。磁盘可用小于 2 GiB 时拒绝创建/执行/发布，定期清理到期成果；清理失败可见且继续占用预算。

下载入口始终核对当前用户、成果归属、工作空间开放及该会话全部业务来源，响应禁止缓存并强制附件。每次下载最大 8 MiB，全局最多 4 路，发送前与分段读取时复核授权；模型只能得到成果描述和标识，不能创建绕过鉴权的公开链接。审计沿用运行和服务端调用记录，新增成果元数据供用户与管理员核查。

## 5. 后续客户端边界和自审

客户端未来可安装同版本 Pi，但只能连接若依受认证的任务接口，使用服务器颁发且绑定用户/运行/有效期的任务授权；能力声明不能变成权限。调用准备、确认、结果认领、取消和文件归属仍由后端决定。当前保留字段和职责说明，不开放任意远程命令端点、额外客户端登录平台或通用多框架协议。

自审：选型依据真实异步工具和取消原型；业务授权复用前两阶段；命令隔离不依赖提示；容量在实际写入与发布前强制；停止覆盖整容器与框架进程；持久事实和崩溃策略不允许盲重试。上述数值须经实际反例验证，未通过则修正方案。Docker [资源限制](https://docs.docker.com/engine/containers/resource_constraints/)和[内存文件系统](https://docs.docker.com/engine/storage/tmpfs/)文档已核对，真实内核配置及限制生效以任务虚拟机验收为准。
